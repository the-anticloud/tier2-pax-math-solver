## What Is PAX Math Solver?

PAX Math Solver is a symbolic mathematics engine combining language model reasoning with SymPy computer algebra. It achieves SOTA results on standardized math benchmarks through program-of-thought (PoT) prompting and self-consistency voting.

- **GSM8K:** 100% (50/50, SOTA-class, saturated)
- **MATH-500:** 84% (42/50, competitive with frontier)
- **AIME:** 16% on 25-question subset

The engine uses the PAX Inference Core to generate code solutions, executes them with SymPy, and validates numerical results.

## Architecture

```
Math Problem (natural language)
    ↓
PAX Inference Core (generates candidate solutions)
    ↓
SymPy Code Generation + Solver
    ↓
[Solution₁, Solution₂, Solution₃, Solution₄] (k=4)
    ↓
Self-Consistency Voting
    ↓
Final Answer + Confidence Score
```

### Layer 1: Problem Understanding
- Extract numerical constraints
- Identify problem type (algebra, geometry, calculus)
- Determine solution strategy hints

### Layer 2: Solution Generation (k=4)
- Generate k=4 independent code solutions (temperature=1.0)
- Each solution is a complete Python program
- SymPy for symbolic manipulation
- NumPy for numerical computation

### Layer 3: Code Execution & Verification
- Restricted execution sandbox (no I/O, networking, file access)
- SymPy evaluation
- Numerical stability checking
- Timeout protection (10 sec per attempt)

### Layer 4: Self-Consistency Voting
- Aggregate k=4 solutions
- Vote on final answer
- Confidence score based on agreement
- Fallback to nearest-match if no consensus

## Quick Start

### Installation
```bash
pip install pax-math-solver sympy numpy

# Or from source
git clone https://github.com/0-1-gg/pax-math-solver.git
cd pax-math-solver
pip install -e .
```

### Basic Usage
```python
from pax_math import MathSolver

solver = MathSolver(
    inference_backend="http://localhost:8000",  # PAX Inference Core
    k=4,  # self-consistency samples
    timeout=10
)

problem = "If a + b = 7 and a * b = 12, what is a² + b²?"
solution = solver.solve(problem)

print(f"Answer: {solution.answer}")
print(f"Confidence: {solution.confidence:.2f}")
print(f"Solution path: {solution.code}")
```

### Advanced: Custom Solver Strategy
```python
solver = MathSolver(
    solver_strategy='hybrid',  # 'pure_sympy', 'lm_only', 'hybrid'
    enabling_features=['numerical_approximation', 'graphing'],
    model="pax-one-l5-narrow-27b"
)

# Solve with constraints
result = solver.solve_with_constraints(
    problem=problem,
    constraints=["answer must be positive integer"],
    return_all_candidates=True
)
```

### CLI
```bash

```

## How SymPy Integration Works

```python
# Generated by PAX Inference Core:
from sympy import symbols, solve, simplify
a, b = symbols('a b')

# Given: a + b = 7, a * b = 12
# Find: a² + b²

sum_sq = a**2 + b**2
sum_sq_expr = (a + b)**2 - 2*a*b

result = sum_sq_expr.subs({a + b: 7, a*b: 12})
answer = simplify(result)  # 25
```

## Solver Strategies

### Strategy 1: Pure SymPy (Symbolic)
- Direct symbolic manipulation
- No LLM inference
- Deterministic output
- Limited to well-formed problems

### Strategy 2: LM-Only (Reasoning)
- Pure language model chain-of-thought
- Numeric approximation
- Handles ambiguity well
- Prone to arithmetic errors

### Strategy 3: Hybrid (Program-of-Thought)
- LM generates code → SymPy executes
- Self-consistency voting across k solutions
- Best accuracy on standardized benchmarks
- **Currently in production**
